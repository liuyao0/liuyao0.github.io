2. 退出码 137 的含义

Linux 进程退出码通常可以表示为：

信号 9 是：

这说明进程被操作系统或外部管理组件强制终止。SIGKILL 无法被进程捕获，所以 Python 来不及打印 traceback。

常见原因包括：

  • 容器内存超过限制，被 OOM Killer 杀掉；
  • Kubernetes 或作业调度器主动终止进程；
  • 管理员手动执行 kill -9；
  • 极少数情况下，设备或驱动异常导致外部组件终止进程。

6. 什么是 cgroup

cgroup 全称是 Control Group，是 Linux 内核用于限制、统计和隔离进程资源的一套机制。

它可以控制或统计CPU 使用量、主机内存使用量、Swap、进程数量、块设备 I/O、其他系统资源等。

Kubernetes 的 Pod/Container 内存限制最终通常由 cgroup 实现。

8. 解决办法

将容器内存限制从 16 GiB 提升到 56 GiB。

扩容后：

  • torch.cuda.is_available() 可以正常完成；
  • vLLM 推理服务可以正常启动；
  • 不再出现 Killed；
  • oom_kill 计数不再继续增长。
