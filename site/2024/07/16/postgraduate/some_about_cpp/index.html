格式化字符串

在C++20中，std库终于提供了生成格式化std::string对象的方法std::format！

std::format中不能使用%d %c这样的格式控制符，因此另附std::format的格式控制符表：

{}: 默认格式化（适用于大多数类型）
{0}: 按照索引格式化（支持多参数时指定）
{:d}: 格式化为整数
{:f}: 格式化为浮点数
{:s}: 格式化为字符串
{:x}: 格式化为十六进制整数
{:X}: 格式化为十六进制整数（大写）
{:e}: 格式化为科学记数法
{:c}: 格式化为字符
{:>width}: 右对齐，宽度为 width
{:<width}: 左对齐，宽度为 width
{:^width}: 居中对齐，宽度为 width
{:0width}: 用零填充空白部分，宽度为 width

平台无关的固定位数整数

要定义平台无关的固定位数整数，通常使用uint64_t int32_t等，这些类型定义在头文件<cstdint>中。

override关键字到底是干嘛的？

override关键字检查别基类中是否有对应同名的、函数原型相同的函数，如果没有编译会报错。不使用override关键字，如果不慎实现了一个同名的但函数原型不同的函数，则无法实现多态，且编译器也不认为这是错误。

final关键字

final关键字修饰的虚函数不能被子类重写。
final关键字修饰的类不能被继承。
